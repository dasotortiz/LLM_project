# LLM Project

This repository collects a small set of notebook-driven experiments for cell type annotation and benchmarking on single-cell data. It compares multiple annotation approaches, including scGPT, CellTypist, Random Forest, and Seurat label transfer, then combines their outputs into consensus and benchmark summaries.

## What's in the repo

- [LLM_model/LLM.ipynb](LLM_model/LLM.ipynb) builds a consensus annotation workflow from CellTypist, Random Forest, and Seurat predictions.
- [scGPT/ZeroShot_Reference_Mapping.ipynb](scGPT/ZeroShot_Reference_Mapping.ipynb) runs a zero-shot reference mapping workflow with scGPT.
- [benchmarking/benchmarking.ipynb](benchmarking/benchmarking.ipynb) compares model predictions and calculates benchmark metrics.
- [Label_transfer/Seurat_Label_Transfer.R](Label_transfer/Seurat_Label_Transfer.R) contains the Seurat label transfer workflow.
- The CSV and JSON files in the subfolders are generated outputs from those workflows.

## Repository layout

- [Additional_visualization/](Additional_visualization/) - plots and visual checks

## Requirements

The notebooks assume a Python environment with common single-cell and analysis packages such as:

- pandas
- numpy
- scanpy
- anndata
- scipy
- scikit-learn
- seaborn
- scGPT
- crewai for the consensus notebook

The scGPT notebook can optionally use faiss for faster similarity search.

## Setup

1. Create and activate a Python environment.
2. Install the packages needed for the notebook you want to run.
3. Make sure your data files and model artifacts are available at the paths expected by the notebooks, or update the paths before execution.

## Running the notebooks

Open the notebook you want to run in Jupyter or VS Code and execute the cells top to bottom.

- [scGPT/ZeroShot_Reference_Mapping.ipynb](scGPT/ZeroShot_Reference_Mapping.ipynb) expects scGPT model files under [scGPT/scGPT_human/](scGPT/scGPT_human/) and uses AnnData-based reference and query inputs.
- [LLM_model/LLM.ipynb](LLM_model/LLM.ipynb) reads prediction CSVs from CellTypist, Random Forest, and Seurat, then writes consensus outputs into [LLM_model/results/](LLM_model/results/).
- [benchmarking/benchmarking.ipynb](benchmarking/benchmarking.ipynb) aligns the model outputs and writes benchmark-ready CSV and JSON summaries.

## Notes

- Several notebooks use absolute file paths that point to a local workspace layout. If you clone this repository elsewhere, update those paths before running the notebooks.
- The consensus notebook expects a Hugging Face token in one of the standard environment variables, or it will prompt interactively.
- Generated outputs are kept in the repository so results are easy to inspect, but they can be regenerated by rerunning the notebooks.

## Outputs

Common generated files include:

- consensus result tables and metrics from the LLM notebook
- scGPT prediction probabilities and labels
- benchmark comparison CSV and JSON summaries
- Seurat label transfer predictions

## Reproducibility

If you are preparing this repository for public use, the next useful step is to replace notebook-local paths with relative paths or configuration variables so the workflows are portable across machines.
